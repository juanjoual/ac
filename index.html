Programa

Sintaxis admitida
  • ARM A32 con registros R0–R15 (también SP, LR, PC). Leer R15 devuelve PC + 8, como en el libro.
  • Instrucciones del capítulo 7: ADD SUB AND ORR con registro o #inmediato, LDR y STR con [Rn, #desp], y B.
  • Ampliaciones de los ejercicios: EOR RSB BIC MOV MVN CMP CMN TST LSL LSR ASR BL NOP.
  • Sufijo S para actualizar NZCV y condiciones en cualquier instrucción: ADDS, MOVGT, SUBSNE, BEQ, BLT…
  • Directivas: .org 0x20 fija la dirección de las instrucciones siguientes, .reg R1 = 5 y .mem 0x100: 5, 8, 13 dan valores iniciales (palabras de 4 bytes) y .equ ARRAY, 0x100 define una constante.
  • Carga de constantes como en las transparencias: ldr R6, =ARRAY. Se comporta como un LDR que lee el literal pool.
  • Comentarios con //, ;, @ o # texto. Puedes pegar el código de las transparencias tal cual, en minúsculas y con tabuladores.

    La Hazard Unit del libro

    Sección 7.5.3

    Anticipación

    Si la instrucción en Execute lee un registro que va a escribir otra en Memory o Writeback, el operando llega desde ALUOutM o ResultW. Memory tiene prioridad porque su instrucción es más reciente. ForwardBE es igual con RA2E.

    if      (Match_1E_M · RegWriteM) ForwardAE = 10  // ALUOutM
else if (Match_1E_W · RegWriteW) ForwardAE = 01  // ResultW
else                              ForwardAE = 00  // RD1E

    Bloqueo por LDR

    LDR no tiene el dato hasta el final de Memory, así que la instrucción que lo usa justo después espera un ciclo en Decode y entra una burbuja en Execute.

    Match_12D_E = (RA1D == WA3E) + (RA2D == WA3E)
LDRstall    = Match_12D_E · MemtoRegE

    Saltos y escrituras del PC

    B se decide en Execute: si se toma, se anulan las 2 instrucciones buscadas detrás. Una escritura de R15 bloquea Fetch hasta que llega a Writeback.

    PCWrPendingF = PCSrcD + PCSrcE + PCSrcM
StallD = LDRstall
StallF = LDRstall + PCWrPendingF
FlushE = LDRstall + BranchTakenE
FlushD = PCWrPendingF + PCSrcW + BranchTakenE

    Riesgos estructurales

    El libro separa la memoria de instrucciones y la de datos, así que no los tiene. Con la opción «Memoria única» puedes ver qué pasaría si Fetch y Memory compartieran una sola memoria.
